# Images referenced by the README

All captured from a clean install seeded with `cairn demo-init && cairn demo-seed`,
headless Chrome at 1400x900, 2x device scale.

- `evals-list.png` — the eval list, with runs stacked as stones.
- `eval-runs.png` — one run: its row, note, metadata, and the report the evaluator produced.
- `eval-compare.png` — the same run compared against two others, with coloured deltas.
- `datasets.png` — the dataset list.
- `dataset-rows.png` — one dataset: ingest history and rows.
- `report.png` — a report opened full width.
- `create-eval.png` — the table.yaml form, with its help beside it.
- `add-data.png` — adding data through the form generated from the ingest script.
- `run-eval.png` — running an evaluation, with the config from `run.py`.
- `eval-running.png` — a started run, its inference running elsewhere.
- `help.png` — the bundled manual at `/help`.
